## AI 대화 기록

**Q1. 파이썬 py파일 exe빌드에 대해 자세히 알려줘.**

- 답변: 터미널(CMD)에서 PyInstaller 설치하기, 실행 파일 하나로 포장하기(pyinstaller --onefile your_script.py)
- 적용 결과: 빌드 성공. 다만 (.exe)파일 켜지지 않음.

**Q2. 원리에 대해 설명해줘.**

- 답변: 파이썬(.py)파일을 (.exe)파일로 변환하는 기술적 원리는 코드를 완전히 컴파일(변환)하는 것이 아님. PyInstaller와 같은 도구가 작동하는 방식은 크게 3가지로 나뉨. 재료모으기 -> 단일파일압축 -> 실행시자동압축해제. 도구가 코드를 분석해 프로그램 실행에 필요한 모든 것을 한 곳에 모음. ​--onefile 옵션을 주면 실행기, 라이브러리, 소스코드를 하나의 큰 (.exe)파일로 압축함.(파이썬 몸체가 통으로 들어감으로써 MB로 커짐.) 사용자가 (.exe)파일을 클릭하면 압축이 풀리면서 임시공간 안에 가상환경이 만들어지고 코드가 실행됩니다. 프로그램을 종료하면서 임시 파일은 삭제됩니다.
- 적용 결과: (.exe)파일 외, 다른 파일이 거슬렸지만 건들지 않기로함.

**03. (.exe)파일을 실행했을 때 바로 꺼지는 이유를 알려줘.**

- 답변: 경로(path)일 경우, 코드 내부의 파일을 불러올 때, (.exe)파일과의 상대적인 위치가 맞지않으면 FileNotFoundError가 발생해 터집니다. (.exe) 파일이 있는 폴더에 필요한 데이터 파일을 같이 넣어두는 등의 조치가 필요합니다.
- 답변2: PyInstaller가 가끔식 일부 라이브러리를 누락하고 빌드하는 경우가 있음. CMD로 켰을 때, ModuleNotFoundError가 뜬다면 이 경우임. --hidden-import로 누락된 모듈을 넣어줘야한다.
- 답변3: 백신 프로그램의 차단, 파이썬 (.exe)파일은 압축을 풀고 가상 환경을 만드는 독특한 방식을 씀. 이를 트로이 목마로 인식해 실행을 강제로 차단하거나, 파일을 격리해버림. 검사 예외 대상에 파일을 등록하는 방법이 있음.
- 시행 착오: pygame 설치 안됨. 사유는 thonny IDE의 버전 업데이트. 구버전 다운로드로 해결.
- 시행 착오2: 경로(path)문제 해결을 위해, (.py) 코드 수정. 성공.
- 시행 착오3: 여전히 실행 안됨. 아마도 사유는 움직이는 애니메이션이 없어서 그런 것이라 추정. 빠른 시일 내 에셋 구하도록함.
- 최종 해결: 아직은 보류.

## 배운점

**1**
- CMD에 입력만 하니, 알아서 (.exe)파일로 만들어주는 것이 신기했다. 만들면서 복잡한 문자가 촤르륵 뜨는 것도 신기했다.

**2**
